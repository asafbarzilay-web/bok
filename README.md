# בוק · משימת סיום לקורס "טלפונית" (כיתה ז')

להדביק את הקובץ הזה בשיחה חדשה עם Claude, יחד עם שאר הקבצים בתיקייה.

## הקבצים
- index.html: האפליקציה עצמה, בקובץ אחד.
- bok-cards.pdf: כרטיסי צבע להדפסה לרמה 3. להדפיס בצבע, סט אחד לכל זוג.
- מצגת-מיומנות-ומבחן-סיום.pdf: מצגת הסיום. שקפים 5–7 הם הבסיס, שפת "בוק" ושפת "טאל".

## הרעיון
בוק הוא חתול שמבין רק את השפה שלו. את המילים מקלידים, וחלק מהדקדוק עובר דרך החושים של הטלפון. בכל רמה יש מטרה ברורה ויומן ניסויים בצורה "מה עשינו ← מה בוק עשה", ומהיומן מגלים את החוקים. בסוף כל רמה התלמידים מנסחים את החוקים שגילו.

- רמה 1 · בוק רעב: מאכילים את בוק בשלושה דגים.
  - על הקיר כתוב: זיל = דג, שלט = ספר, מיר = ילד.
  - "רה" בתחילת מילה הופך לגדול, ו"אן" בסוף הופך לשלושה.
  - מחזיקים את הטלפון כמו מגש ומטים אותו כדי לגלגל את האוכל. בטלפון בלי חיישן תנועה אפשר לגרור באצבע.
  - בוק אוכל רק דגים גדולים. על דג קטן הוא אומר "נו טול… רהזיל!".
- רמה 2 · בוק עייף: מרדימים את בוק.
  - צריך חושך (מכסים את המצלמה), שקט, טלפון יציב, והספר שלו (מקלידים "שלט").
  - הרמז לספר: בוק אומר "אלשלט".
  - החריג: רעש מעיר אותו, אבל זמזום נמוך הוא שיר ערש ומרדים מהר יותר.
- רמה 3 · יום הולדת: אופים עוגה.
  - מראים צבעים למצלמה האחורית: פלו צהוב, מוז כחול, תיק אדום, ליב ירוק.
  - ניעור הטלפון = טרר. הפיכתו על השולחן = תנור. 2–5 שניות = חום, 6 שניות ומעלה = רהחום.
  - בספר המתכונים יש שתי דוגמאות בלי הסבר: 🥞 "פלו · מוז · טרר · חום" ו־🥤 "תיקאן · מוז · טרר".
  - המטרה, העוגה 🎂: "פלואן · מוז · אלתיק · טרר · רהחום".
  - אחרי כל אפייה האפליקציה מתרגמת לשפת בוק את מה שעשיתם בפועל.
